## ADR-001: Acquisition policy

**Context.** The Sandbox convention is static, manually downloaded data with no live API calls. Verification work and the throw-away probe `scripts/feasibility_probe.py` used live endpoints.
**Decision.** Production stages are offline. The only network code lives in `src/ingest/acquire.py`, runs only with `--allow-network`, writes only under `data/raw/`, never overwrites, rejects unexpected content types, and records size, SHA-256, retrieval time and response headers per file.
**Consequences.** A fresh clone reproduces results from the hashed raw files; refreshing a source is a deliberate, logged act. The probe script is not part of the pipeline and should be moved to `scripts/probes/` or deleted before the first commit.
